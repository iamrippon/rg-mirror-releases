# RG Mirror Releases

**RG Mirror** is a screen-mirroring application project by [RG Studios](https://rg-studios.in/).

This public repository is used only for **official release downloads and public release information**. Application source code is proprietary and is not published here.

## Downloads

No official release has been published yet. When a version is available, downloads will be listed on the [Releases page](https://github.com/iamrippon/rg-mirror-releases/releases).

## Release notes

Each release should include:
- Version number and publication date
- Supported Windows versions and system requirements
- New features and fixes
- Known issues and limitations
- Installer download and SHA-256 checksum

## Installation and safety

Only download installers attached to releases in this repository. Verify the published checksum before installing. Do not install unofficial builds claiming to be RG Mirror.

## Project status

RG Mirror is under development. Do not assume iPad mirroring, audio, wireless discovery, USB connectivity, or any other capability is available until it is documented in a specific release and tested.
